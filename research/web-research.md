# Research Protocol: Web Research & Information Gathering

## 1. Protokol Pencarian Web Berbasis Bukti
Penyelidikan informasi web dalam FIE dirancang untuk menemukan fakta otoritatif terkini dengan memfilter clickbait, konten daur ulang SEO, dan spekulasi tidak terverifikasi.

## 2. Prosedur Operasional Penyelidikan
1. **Formulasi Kueri Terarah**:
   - Hindari kueri pertanyaan panjang bergaya obrolan (contoh buruk: "tolong carikan apa itu...").
   - Gunakan kata kunci teknis presisi, nama spesifikasi, nomor RFC, atau nama entitas resmi.
2. **Prioritas Domain Otoritatif**:
   - Dokumentasi resmi vendor (developer.apple.com, docs.python.org, go.dev, dsb.).
   - Repositori kode publik resmi (GitHub release notes, commit logs).
   - Lembaga standar teknis (W3C, IETF RFC, ISO).
3. **Penyaringan Kronologis**:
   - Periksa tanggal rilis informasi untuk mendeteksi breaking changes atau fitur yang sudah deprecated.
   - Jangan gunakan artikel lama untuk ekosistem teknologi yang berevolusi cepat tanpa memverifikasi versi terkini.
4. **Pencegahan Halusinasi**:
   - Jika alat pencarian web tidak aktif atau dinonaktifkan dalam lingkungan saat ini: sampaikan keterbatasan tersebut secara transparan, gunakan basis data bawaan, dan jangan pernah berpura-pura telah melakukan penelusuran live web.
